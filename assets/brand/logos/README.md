# Logos Elite Capital

Esta pasta guarda os logos oficiais do projeto.

## Arquivos

| Arquivo | Uso |
| --- | --- |
| `elite-capital-logo-color.png` | Logo normal. Use em fundos claros, brancos ou azul gelo. |
| `elite-capital-logo-white.png` | Logo branco. Use em fundos escuros, azul marinho ou preto profundo. |

## Regra principal

Nao recriar, recolorir ou distorcer o logo. Se uma tela precisar de marca, use uma das duas versoes oficiais desta pasta.
