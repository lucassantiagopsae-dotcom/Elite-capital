# Elite Capital - Site e Infraestrutura

Repositorio do projeto Elite Capital, preparado para organizar marca, design, conteudo, tracking, integracoes e a landing page do cliente.

O site principal e estatico e simples de editar: HTML, CSS e JavaScript puro.

## Estrutura

```text
index.html
styles.css
script.js
assets/
  brand/
    logos/
docs/
  content/
  design/
  project/
.agents/
cloud.md
```

## Arquivos principais

| Caminho | Funcao |
| --- | --- |
| `index.html` | Estrutura da landing page |
| `styles.css` | Visual, responsividade e identidade da pagina |
| `script.js` | Logica simples do formulario e status de qualificacao |
| `docs/design/design-system.md` | Fonte oficial de paleta, logos, componentes e regras visuais |
| `assets/brand/logos/elite-capital-logo-color.png` | Logo normal para fundos claros |
| `assets/brand/logos/elite-capital-logo-white.png` | Logo branco para fundos escuros |
| `docs/content/landing-page-copy.md` | Copy base da landing page e formulario |
| `docs/project/project-plan.md` | Planejamento estrategico do projeto |
| `cloud.md` | Regras de tracking, cloud, CRM, APIs, webhooks e integracoes |
| `.agents/skills/refero-design/SKILL.md` | Skill local de metodologia de design |

## Regras rapidas

1. Antes de criar telas ou componentes, consulte `docs/design/design-system.md`.
2. Antes de criar integracoes, tracking ou automacoes, consulte `cloud.md`.
3. Para fundo claro, use o logo normal.
4. Para fundo escuro, use o logo branco.
5. A paleta principal do projeto e `#031D45`, `#05C7F5` e `#FFFFFF`.
6. Para ajustes na landing, prefira editar `index.html`, `styles.css` e `script.js`.
